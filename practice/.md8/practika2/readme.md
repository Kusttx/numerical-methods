# Практическая работа

## Тема
Метод Ньютона и метод секущих.

## Задание 2
Исследование уравнения `e^x - k*x = 0` при разных значениях параметра `k`.

## Содержание проекта

- `results.md` — результаты выполнения задания и ответы на вопросы.
- `screenshots/` — скриншоты работы программы.
- `README.md` — описание практической работы.

## Используемые методы

- Метод Ньютона.
- Метод секущих.
- Метод половинного деления.

## Результат

Проведено исследование уравнения при `k = 1`, `k = e`, `k = 3` и `k = 5`. Найдены корни и сравнено количество итераций разных методов.
