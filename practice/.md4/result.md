По результатам эксперимента NumPy оказался быстрее обычных циклов Python во всех 11 заданиях.

Наибольшее ускорение показали:

2. Замена отрицательных значений — **280,1×**.
3. Поиск максимума и его индекса — **203,0×**.
4. Сумма по строкам — **200,6×**.

Наименьшее ускорение показала фильтрация положительных значений — **13,0×**, однако и в этом случае NumPy оказался быстрее.

**Итог:** NumPy значительно ускоряет обработку массивов и матриц благодаря оптимизированным операциям. Код с NumPy часто получается короче и понятнее. При этом важно учитывать расход памяти на временные массивы и небольшие погрешности вычислений с плавающей точкой.
