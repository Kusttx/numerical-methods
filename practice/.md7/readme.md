# Результаты работы

В ходе выполнения задания была рассмотрена функция:

f(x) = x^3 - 6x^2 + 11x - 6

Был построен график функции на отрезке [0, 4] и определены три интервала локализации корней:

- [0.5, 1.5]
- [1.5, 2.5]
- [2.5, 3.5]

С помощью метода половинного деления получены следующие результаты:

1. Первый корень: x = 1. Количество итераций — 1.
2. Второй корень: x = 2. Количество итераций — 1.
3. Третий корень: x = 3. Количество итераций — 1.

Аналитическое разложение полинома:

f(x) = (x - 1)(x - 2)(x - 3)

Абсолютная погрешность всех трёх корней равна 0. Относительная погрешность также равна 0.

Теоретическое количество итераций для каждого интервала при точности 10^-9 составляет 30.
