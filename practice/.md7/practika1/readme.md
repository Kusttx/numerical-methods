## Задание 1. Поиск корней полинома

Функция: `f(x) = x³ - 6x² + 11x - 6`

### Ответы на вопросы

1. Корни находятся на интервалах около 1, 2 и 3.
2. Найдены три корня: 1, 2 и 3.
3. Аналитически: `f(x) = (x - 1)(x - 2)(x - 3)`.
4. Число итераций зависит от длины начального интервала. Чем он меньше, тем меньше итераций.
5. Численные корни совпадают с аналитическими с заданной точностью.
6. Абсолютная и относительная погрешности очень малы.
7. Число итераций примерно совпадает с теоретической оценкой
